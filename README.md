# RISING ANTICHEAT

Античит-плагин для **Purpur / Paper 1.21.4** (Java 21).

## Что умеет

- **Проверки боя:** Reach, KillAura (удар мимо прицела, несколько целей сразу, удар сквозь блоки, слишком частые удары), AimAssist (резкий снап на цель).
- **X-Ray детект:** слишком много разных жил руды за малое число сломанных блоков.
- **Ступени реакции** (пороги настраиваются в `config.yml`):
  1. Подозрительные удары **не регистрируются**.
  2. Если продолжается — **админам пишется в чат**.
  3. Если продолжается дальше — игрок **телепортируется на точку проверки** (`/setcheter`), замораживается, на экране большой `title`: *ВАШЕ ПОВЕДЕНИЕ ПОДОЗРИТЕЛЬНО / Подождите администратора*. Админам приходят две кнопки:
     - 🟢 **[✔ ПРОШЁЛ ПРОВЕРКУ]** — игрок телепортируется на спавн и размораживается;
     - 🔴 **[✖ ЧИТЕР — БАН]** — бан по причине «Читы».
- Если игрок вышел во время проверки — бан (можно отключить: `ban-on-quit: false`).

## Команды и права

| Команда | Описание |
|---|---|
| `/setcheter` | Задать точку проверки (где стоите) |
| `/rac check <ник>` | Отправить на проверку вручную |
| `/rac pass <ник>` | Игрок прошёл проверку |
| `/rac ban <ник>` | Бан за читы (только для игрока на проверке) |
| `/rac vl <ник>` | Показать нарушения |
| `/rac reload` | Перезагрузить конфиг |

Права: `rac.admin` (по умолчанию op) — команды и алерты; `rac.bypass` — игнорируется античитом.

## Как собрать (способ 1 — через GitHub, ничего устанавливать не нужно)

1. Зарегистрируйтесь на https://github.com и нажмите **New repository** → название `RisingAntiCheat` → **Create repository**.
2. Распакуйте архив проекта. В репозитории нажмите **uploading an existing file** и перетащите **всё содержимое папки** (папки `src`, `.github`, файлы `pom.xml`, `README.md`, `.gitignore`). Важно, чтобы папка `.github` загрузилась (она скрытая — на Windows включите «Показывать скрытые файлы»). Нажмите **Commit changes**.
   - Если `.github` не загрузилась: **Add file → Create new file**, имя `.github/workflows/build.yml`, вставьте содержимое файла из архива.
3. Откройте вкладку **Actions** — сборка запустится сама. Подождите 1–2 минуты до зелёной галочки.
4. Откройте последний запуск → внизу раздел **Artifacts** → скачайте **RisingAntiCheat** (внутри zip будет `RisingAntiCheat.jar`).
5. Если сборка не запустилась: Actions → *Build RisingAntiCheat* → **Run workflow**.

Готовый релиз на странице репозитория: создайте тег — `git tag v1.0.0 && git push origin v1.0.0` (или **Releases → Draft a new release** с тегом `v1.0.0`), jar прикрепится автоматически.

## Как собрать (способ 2 — на своём компьютере)

Нужны **JDK 21** и **Maven 3.9+**:

```
mvn clean package
```

Файл появится в `target/RisingAntiCheat.jar`.

## Установка

1. Положите `RisingAntiCheat.jar` в папку `plugins` сервера Purpur 1.21.4 и перезапустите сервер.
2. Встаньте на место для проверки читеров и выполните `/setcheter`.
3. Настройте пороги и команду бана в `plugins/RisingAntiCheat/config.yml` (если используете LiteBans и т.п. — поменяйте `ban-command`).

## Встроенный Anti-X-Ray (рекомендуется включить)

Помимо детекта в плагине, включите скрытие руды на уровне сервера. В файле `config/paper-world-defaults.yml`:

```yaml
anticheat:
  anti-xray:
    enabled: true
    engine-mode: 2
```

Затем перезапустите сервер (режим 2 подменяет скрытую руду «фейковыми» блоками, поэтому X-Ray клиенты видят мусор).

## Важно

Эвристики (особенно AimAssist) не дают 100% точности — поэтому плагин сначала отменяет удары и зовёт админа, а не банит автоматически. Подстройте значения в `config.yml` под свой сервер.
